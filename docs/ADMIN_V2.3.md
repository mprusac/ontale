# Administracija — nove stranice u v2.3

Sve se mijenja bez diranja koda; svaka radnja ide u *Dnevnik izmjena*.

| Stranica | Što se radi |
|---|---|
| **Moderacija → Prijavljene poruke** | pošiljatelj, primatelj, razlog, tekst; *Kontekst* (najviše 4 poruke oko prijavljene — cijeli razgovor admin ne vidi); *Ukloni poruku*; *Ukloni + blokiraj pošiljatelja* (blokira račun, odjavljuje ga); *Odbaci*. Broj novih prijava stoji uz izbornik. |
| **Moderacija → Putokazi** | pretraga po tekstu/nadimku/danu, *samo prijavljeni*; *Ukloni* (s razlogom), *Vrati*, *Odbaci prijave*. |
| **Moderacija → Postavke putokaza** | najveća duljina (20–80, zadano 60), uključeno/isključeno, vidljivost u povijesti lige, dodatne zabranjene riječi. Istek je uvijek kraj dana partije. |
| **Obavijesti i e-mail** | stanje SMTP-a, broj igrača s privolom, *probni e-mail*, *pokreni zakazane poslove*, pravila podsjetnika (dani neaktivnosti, razmak, najviše po razdoblju, sat slanja, razmak sažetaka poruka), obavijest svim igračima, statistika vrsta obavijesti, dnevnik isporuke (poslano / greška / preskočeno) i zakazanih poslova. |
| **Izazovi prijatelja** | pretraga po nadimku i stanju; rezultat; *Otkaži* za izazove na čekanju ili prihvaćene (zlouporaba). |
| **Zvuk** | uključenost na stranici, zadano uključen za nove posjetitelje, zadana glasnoća; popis zapisa s preslušavanjem (▶) i isključivanjem; dodjela zvuka svakom događaju i svakom gradu na rutama; dodavanje vlastitog zapisa (MP3/OGG/WAV/WebM do 400 kB, licenca obavezna). |
| **Karta i podloge** | zadani prikaz (Reljef/Satelit), pružatelj (automatski/MapTiler/Stadia/besplatno/prilagođeno), vlastiti stil reljefa, vlastiti satelit, atribucija, zatamnjenje satelita, rezervna podloga, EOX (samo nekomercijalno). Prikazuje jesu li ključevi postavljeni u `.env` (ključevi se ne upisuju u admin). |
